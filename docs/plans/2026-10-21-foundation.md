# Foundation (Sub-project 1) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A local and hosted Supabase database with the full data model, row-level security and seed data, plus an Expo Android app skeleton (custom dev build) with four labelled tabs and French-by-default translations.

**Architecture:** One git repo with two parts: `supabase/` (SQL migrations, seed, pgTAP tests run with the Supabase CLI against a local Docker database) and `app/` (Expo + expo-router + TypeScript). The app talks to Supabase only through `@supabase/supabase-js`; all access rules live in RLS policies and column grants. No feature logic yet — later sub-projects build on these tables and screens.

**Tech Stack:** Supabase CLI (Postgres 15+, PostGIS, pgvector, pg_trgm, unaccent, pgTAP), Expo (latest stable SDK at scaffold time) with expo-router and expo-dev-client, TypeScript, i18next + react-i18next + expo-localization, lucide-react-native, Jest (jest-expo) + @testing-library/react-native, ESLint with eslint-plugin-i18next, GitHub Actions.

**Spec:** `docs/specs/2026-10-21-friend-app-design.md` (sections 3, 4, 7, 8 "Navigation", 9, 13, 14 item 1)

## Global Constraints

- France only; Supabase hosted project region: **EU (Paris, `eu-west-3`)**.
- 18+ only: `profiles.age_confirmed` must exist; sign-up flow (sub-project 4) sets it.
- **French is the default UI language regardless of phone settings**; English available. Stored values: `'fr'` | `'en'`.
- **No hard-coded UI text**: every user-visible string comes from `app/src/i18n/locales/{fr,en}.json`.
- **No emoji anywhere in the app UI** (translation files included). Icons: Lucide only, always paired with a text label.
- Exact location is never exposed: `profiles.home_area` is readable only by its owner and admins.
- Participants are never graded: no participant score column exists anywhere.
- Embedding model fixed for the whole project: `intfloat/multilingual-e5-small` → `vector(384)`.
- Times stored as `timestamptz`; activity timezone default `'Europe/Paris'`.
- Commit after every task; commit messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **Anonymous browsing** (no account): `anon` must read categories, tags, ambiance words, associations, activities, sessions, public profile view and badges — and nothing private (profiles base table, interests, feedback, reports). → tests in Tasks 2, 3, 4.
2. **Self-promotion**: a signed-in user updating their own `role`, `phone_verified` or `supporter` must be refused. → test in Task 2.
3. **Unusual device language tags** (`en-GB`, `en_US`, `EN`, `fr-CA`, `de-DE`, empty, `null`) must resolve to the agreed rule without crashing. → tests in Task 8.
4. **Blocked users in group chat**: messages from someone the viewer blocked must not be returned to the viewer. → test in Task 5.
5. **Account deletion (GDPR erasure)**: deleting an auth user removes their profile and everything they own (activities, memberships, messages…) without a foreign-key error. → test in Task 5.

**Interfaces:**

- Produces (npm scripts at root): `db:start`, `db:reset`, `db:test`, `db:types`.

Prerequisites the README lists: Node 22 LTS, Docker Desktop (running), Android Studio with an emulator (API 34+), Git.

**Interfaces:**

Access rules:

| Table | anon | authenticated | admin |
|---|---|---|---|
| profiles (base) | none | select/update own row; update only columns `first_name, photo_url, bio, home_area, home_area_label, language, age_confirmed` (column grants) | all |
| public_profiles view | select | select | select |

| user_interests | none | all on own rows | select |
| category_requests | none | insert own (status must be `pending`), select own | all |
